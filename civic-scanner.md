# Civic Scanner quick reference

The current portable skill starts at [`SKILL.md`](SKILL.md). Install and platform instructions are in [`README.md`](README.md). The six modes are `daily-scan`, `full-pipeline`, `verify-only`, `research`, `legal-threat`, and `discover`. Scans cover civic developments across public agencies, schools, business, housing, health, transport, environment, culture, and community life, using a declared source inventory and date window.

For daily scans, review [`references/daily-scan.md`](references/daily-scan.md) before reporting. It requires an all-actions meeting ledger, full chronological review of available transcript or recording ranges, and reconciliation with agendas and minutes. A future-agenda motion is a separate action from a vote on the underlying policy. If any required range, cue, or source is unresolved, label the run `PARTIAL`.
